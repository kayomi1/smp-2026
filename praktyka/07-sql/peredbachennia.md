# Мої передбачення

| # | Запит | Передбачення |
| --- | --- | --- |
| A | `SELECT 7 / 2, 7 / 2.0` | Перше покаже 3 без остатку, а друге покаже 3.5 |
| B | `SELECT COUNT(*), COUNT(Composer) FROM Track` | Буде показ всієї кількості строк у таблиці Track, та кілкість рядків у яких стовпець Composer не є NULL |
| C | `SELECT 'Abba' LIKE 'a%', 'Abba' = 'abba'` | буде 1 (істина) та 0 (хиба), тому що LIKE все одно на реєстр, а знаку `=` не все одно |
| D | `SELECT Composer FROM Track ORDER BY Composer LIMIT 1` | Покаже NULL тому що йде сортування по зростанню і тому перші рядки будуть с композиторами які мають значення NULL |
| E | `SELECT NULL OR 1, NULL AND 1` | покаже 1 та NULL, 1 буде тому, що одна з умов є істиною, тому ця істина й буде результатом, а у другому результат залежить від невідомого значення, тому й результат буде невідомий |

A. Показав `3 | 3.5`. Я **Вгадав**
B. Показав `3503 | 2526`. Я напевно **Вгадав**
C. Показав `1 | 0`. Я **Вгадав**
D. Показав `NULL`. Я **Вгадав**
E. Показав `1 | NULL`. Я **Вгадав**
