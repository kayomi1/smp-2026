# Висновок: вибір формату конфігурації

Для бота піцерії я б обрав TOML. У ньому є коментарі, тож можна пояснити, чому ліміт замовлень саме такий, а в JSON цього зробити не можна. TOML не має пасток YAML: рядок завжди в лапках, тому `off`, `NO` чи `1.10` не перетворяться на булеве значення або число. Файл читається як звичайний список налаштувань, і його зможе відредагувати адміністратор без досвіду програмування. YAML теж зручний, але одна забута пара лапок може змінити тип значення.
