# Мої передбачення

| # | Код | Передбачення |
| --- | --- | --- |
| A | *re.search(r'"(.*)"', ryadok).group(1)* | дає все від першої лапки до останньої, бо `.*` жадібний |
| B | *re.search(r'"(.*?)"', ryadok).group(1)* | дає до найближчої закривної лапки, бо `.*?` нежадібний: тобто тільки від GET до HTTP/1.1 |
| C | *re.search(r'(\d{3}) (\d+)', ryadok).groups()* | шукає три цифри потім пробіл потім ще цифри: підходить тільки `('200', '30522')` |
| D | *re.findall(r'\d+\.\d+', ryadok)* | шукає цифра потім точка потім цифра |
| E | *re.sub(r'((\d+)/(\w+))/(\d+)', r'\4 \3 \2', '17/Mar/2026') | sub із групами `1 = 17/Mar, 2 = 17, 3 = Mar, 4 = 2026`, та шаблон їх робить у порядку 4, 3, 2, тобто - **`2026 Mar 17`**. |
