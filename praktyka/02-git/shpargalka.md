# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git status` | Показує у якій ти гілці, що змінилось та що готове та не готове до коміту | Перед кожним комітом, щоб не забути ніякі файли до коміту |
| `git clone` | Копіює репозиторій з GitHub на комп'ютер | Коли починаю роботу з проектом у репозиторії |
| `git diff` | Показує, що саме змінилось у файлах | Коли хочу перевірити які зміни відбулись перед ти щоб додати файли завдяки `add` |
| `git add` | Додає файли до індексу та якби відмічає іх, як готові до коміту | Після правки файлів та перед кожним комітов щоб вибрати файли |
| `git commit` | Зберігає якби "знімок" проєкту у новий коміт з описом, що було змінено | Коли зробив всі потрібні зміни и хочу їх зберегти |
| `git push` | Відправляє всі зміни/коміти з мого комп'ютера на GitHub | Коли хочу публічно поділитись роботою на ГітХабі чи просто коли хочу зробити бекап |
| `git log` | Показує історію всіх комітів | Коли треба згадати, хто, що і коли робилось |

## Передбачення

| # | Відповідь на питання | Вгадав / Не вгадав |
|---|---|---|
| 1 | `git status` покаже файл і у рядку, що вже готово до коміту та у рядку, що ще не готово до коміту, бо я зробив `add` після додання Рядка 2 та він готовий до коміту, і не робив його після Рядка 3 і він ще не вибраний до коміту | Вгадав |
| 2 | `git diff` покаже додавання рядка 3, а `git diff --staged` покаже додавання рядка 2 | вгадав |
| 3 | У коміт потрапить лише Рядок 1 та Рядок 2, тому що Рядок 3 ще не в індексі, `git status` покаже що файл eksperyment.txt не вибран для коміту тому, що я не робив `add` після додання Рядка 3 і це якби нова зміна | вгадав |
